# 貪食蛇遊戲（C 語言）

大二程式設計期末專題，以 C 語言獨立完成，在 Windows 終端機執行。
除了基本玩法，我自行設計了五種道具，讓高分必然伴隨高風險。

## 遊戲規則
- W / A / S / D 控制方向，空白鍵加速
- 撞牆或撞到自己會扣一條命，沒命時遊戲結束
- 每得 10 分進入下一關，移動速度提升

## 道具設計
| 道具 | 出現位置 | 效果 |
|---|---|---|
| f 小食物 | 地圖任意處 | +4 分，蛇身 +1 |
| F 大食物 | 靠牆邊緣 | +6 分，蛇身 +3，原地留下炸彈 |
| + 生命果實 | 左右牆邊 | 多一條命 |
| # 長度縮減器 | 四個角落 | 蛇身減半 |
| x 炸彈 | 吃掉 F 後出現 | 扣一條命 |

## 執行方式
gcc finalsnake.c -o finalsnake
.\finalsnake.exe
##
用 system("cls") 做的終端機遊戲會閃爍是正常的
